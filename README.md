# Jardim de Hafez · باغ حافظ

Plataforma brasileira dedicada à poesia de Hafez de Shiraz: textos originais em persa, traduções
revisadas para o português, a tradição do Fal-e Hafez e o contexto cultural da poesia persa.

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm check        # lint, formatação, tipos, testes e validação do acervo
pnpm generate     # site estático em .output/public
```

Requisitos: Node ≥ 22.12 e pnpm 11.

Documentação em [`docs/`](docs/): visão geral, arquitetura, design system, inventário do Hafiz on Love,
modelo de conteúdo, fluxo de tradução, direitos e fontes, plano de implementação e decisões (ADRs).
